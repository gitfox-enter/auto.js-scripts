# auto.js-scripts (红米/1.5K屏适配 fork)

原仓库: [AdoreJc/auto.js-scripts](https://github.com/AdoreJc/auto.js-scripts)

## 钢琴块2.js 红米 Turbo 4 Pro 适配版

适配屏幕: **1280 x 2772** (1.5K)

| 参数 | 原版(1080p) | 本版(1280x2772) |
|------|------------|----------------|
| 四轨 X 坐标 | 135/405/675/945 | 160/480/800/1120 |
| 检测线 Y | 1111 | 2350 |

### 换算公式(其他机型自查)
- 四轨X = 屏幕宽度 / 8 的奇数倍: w/8, 3w/8, 5w/8, 7w/8
- 检测线Y ≈ 屏幕高度 x 0.85 (越小游戏越早触发,高速歌可再上移)

### 使用
1. 安装 [AutoJs6](https://github.com/SuperMonster003/AutoJs6/releases)
2. 授予无障碍+悬浮窗+截屏权限
3. 先运行本脚本(后台挂起),再进钢琴块2选歌开局
4. 长按块/特殊块可能漏检(单点颜色检测的局限),正常方块全中
